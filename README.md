# Selfish 公司项目管理层

Selfish（自私）是这套理念的公司级项目管理根。当前仓库把它作为公开的项目目录和治理入口使用；法律实体、银行账户、雇佣关系和支付系统尚未登记或上线。

项目管理先于大规模人员注册：人员先用公开 GitHub 账号登记到公司，再申请加入具体子公司。公司登记不等于游戏成员，只有被项目接纳的人才进入该项目的贡献、审查和荣誉范围。

目前的首个子公司是[万国起源游戏](../community/manifesto.md)。它有自己的 owner、代码、MR 审核、commit 权重、账本和收益规则。Selfish 公司管理层维护项目目录、人员登记、项目加入记录和公开证据索引，不直接改写游戏代码、commit 权重、结算结果或 owner 的 MR 决定。

## 公开管理流程

1. 在 GitHub 公开提交人员登记或项目申请。
2. 公司目录记录申请、项目归属、状态和负责人。
3. 子公司负责人确认申请人可以参与的范围。
4. 只有项目成员可以提交该项目的 MR、参与该项目的审查或进入该项目的荣誉榜。
5. 所有变更以 GitHub commit、Issue、Pull Request 和公开快照为证据。

项目目录见 [`projects.json`](projects.json)，人员加入规则见 [`admission.md`](admission.md)。任何人都可以复制这套结构建立自己的项目；复制不自动取得 Selfish 公司或万国起源游戏的名称、权限或收益。

## GitHub 是公开证据层

GitHub 仓库、Issue、PR 和发布文件是当前最优先的公示入口。Gitee、GitCode 或其他平台可以保存同步镜像，但镜像不能覆盖 GitHub 的历史，也不能反向改写本地贡献服务。

本地贡献服务仍然只生成可审计快照；没有配置真实 Bot、支付、身份合并、税务或生产部署前，公开文件不会把它们写成已完成能力。
